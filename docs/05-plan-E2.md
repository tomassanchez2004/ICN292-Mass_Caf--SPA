## 2) Riesgos
- Dificultades durante el desarrollo o integración del software, lo que retrasaría en la implementación. 
- Pérdida o inconsistencia de información. lo que podría generar diferencias entre el sistema y el stock real.
- Problemas de acceso según el rol del usuario, lo que podría darle acceso no autorizado a funciones que debería de tener restringidas.
- Manejo de datos personales de los usuarios, siendo un riesgo de uso o exposición inadecuada de información personal (dificultades asociadas a la Ley 21.719), pudiendo ser necesario el adaptar el uso de datos personales.
## 3) Consideraciones para la Entrega 2
Durante el desarrollo se realizarán pruebas progresivas para verificar que las ventas actualicen correctamente el inventario, que las compras registren los ingresos de productos e ingredientes y que las mermas y alertas funcionen según lo definido en el proceso TO-BE.
Los resultados obtenidos permitirán evaluar si el sistema ayuad a mejorar los indicadores definidos para el problema de inventario de la cafetería.
