# ICN292 - Proyecto Mass Café SPA
Proyecto correspondiente a la Entrega 1 del ramo ICN292.
# PYME
Mass Café SPA - La Cantina del Café. Cafetería de especialidad ubicada en Providencia.
# Problema
El proceso seleccionado es la gestión de inventario. Actualmente se utilizan planillas en papel y el sistema de ventas no permite llevar un control detallado de los ingredientes utilizados. Esto dificulta mantener el stock actualizado y tomar decisiones de compra, generando trabajo adicional, mermas y posibles quiebres de stock.
# Estructura del repositorio
- `docs/`: documentación del proyecto.
- `assets/`: diagramas y otros recursos.
- `informe/`: informe de la Entrega 1 y sus versiones finales.
# Entrega 2
La Entrega 1 corresponde al diagnóstico y diseño preliminar del SIG. El trabajo realizado servirá como base para el desarrollo del sistema en la Entrega 2, incluyendo su implementación y pruebas en localhost.
